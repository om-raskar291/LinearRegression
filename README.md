# 🏥 Insurance Cost Prediction using Linear Regression

## 📌 Overview
This project predicts medical insurance charges based on health, lifestyle, and financial features using Linear Regression.

It demonstrates a complete machine learning workflow including data preprocessing, feature engineering, and model evaluation.

---

## 📊 Dataset
The dataset contains the following features:

- Age, BMI, Number of children
- Smoking status and gender
- Medical history and expenditures
- Salary and region

Target Variable:
- `charges` → Insurance cost

---

## 🔍 Key Steps
- Data Cleaning and Preprocessing
- Encoding Categorical Variables
- Outlier Handling using IQR
- Multicollinearity Detection using VIF
- Model Training using Linear Regression
- Model Evaluation (R² Score, MSE)

---

## 📈 Visualizations
- Distribution plots (Histogram)
- Correlation Heatmap
- Smoker vs Charges (Key Insight)
- Regression Plots
- Actual vs Predicted Comparison

---

## 📊 Results
- Achieved strong model performance with high R² score
- Identified key factors influencing insurance charges

---

## 🔥 Key Insights
- Smoking significantly increases insurance charges
